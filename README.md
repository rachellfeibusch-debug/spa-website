# spa-website

Source for www.strategicpauseadvisory.com. This folder is set up to the layout in the Claude Code Website Guide.

| Folder or file | What it is | Published? |
|---|---|---|
| `CLAUDE.md` | Instructions Claude Code reads automatically: pages, brand rules, quality bar | Yes (harmless) |
| `content/spa-website.md` | Master copy for every page | Yes (harmless) |
| `content/build-prompts.md` | The prompts to paste into Claude Code | Yes (harmless) |
| `images/` | Web-ready images, logos and share image | Yes |
| `fonts/` | Licensed FF Good Headline Pro web fonts | Yes (needed by the site) |
| `files/` | Article PDFs linked from Watch & Listen | Yes |
| `favicon.ico`, `favicon-32.png`, `apple-touch-icon.png` | Browser tab and phone icons | Yes |
| `brand/` | Originals: logo source files, banner, brand guidelines, font purchases, original Word copy | **No** (listed in `.gitignore`) |
| `marketing/` | Anything private | **No** (listed in `.gitignore`) |
